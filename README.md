# Anitej Isaac Sharma — Portfolio

Personal portfolio showcasing my software projects, professional experience,
technical background, and photography.

Live site: [aisaaxs.space](https://aisaaxs.space/)

## Tech stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production server
- `npm run lint` — run ESLint
- `npm run test:a11y` — run automated accessibility and keyboard tests
- `npm run test:a11y:ui` — inspect accessibility tests in Playwright UI mode
- `npm run deps:check` — validate dependency versions and package formatting
- `npm run deps:fix` — fix dependency version mismatches
- `npm run deps:format` — normalize `package.json` formatting and field order
- `npm run deps:list` — inspect declared dependencies
- `npm run deps:update` — interactively update dependencies

The site includes canonical metadata, Open Graph and Twitter previews, JSON-LD
structured data, a sitemap, `robots.txt`, and a web app manifest.

Accessibility decisions, ARIA usage, and the manual testing checklist are
documented in [docs/accessibility.md](docs/accessibility.md).
